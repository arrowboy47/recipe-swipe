# Recipe Pipeline

Part of AK's project system. Full rules live in the vault note `Reference/Guides/Workflow/Project Workflow.md`.

- Vault folder: `~/Documents/Notes/Projects/Recipe Pipeline/`
  - Index: `_Recipe Pipeline Index.md`
  - Backlog: `Recipe Pipeline Backlog.md`
  - Log: `Recipe Pipeline Log.md`
- At the end of every work session: append a dated `## YYYY-MM-DD` entry to the Log (what changed, why, how it was verified) and tick or add items in the Backlog (`- [x] item ✅ YYYY-MM-DD`).
- If the session changed the homelab stack, also add an entry to `Reference/Guides/Stack Log.md`.
- Never commit secrets. `.env` stays local and gitignored.
